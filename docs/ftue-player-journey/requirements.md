# FTUE 및 플레이어 여정 개선 요구사항

## 목표

신규 플레이어가 접속 후 긴 규칙 문서를 먼저 읽지 않아도 다음 흐름을 완주하도록 한다.

`접속 → 방 선택/관전 → 직업 확인 → 첫 밤 행동 → 첫 투표 → 결과 이해 → 한 판 더`

핵심 재미인 정체 추리와 토론을 가리지 않는 범위에서만 안내를 추가한다. 게임 중 계속 떠 있는 별도 튜토리얼 UI나 강제 연습판은 도입하지 않는다.

## 발견한 이탈 위험

| 구간 | 기존 위험 | 개선 기준 |
| --- | --- | --- |
| 첫 화면 | 방 목록만 보여 목표와 다음 행동을 알기 어려움 | 게임 목표, 낮/밤 흐름, 로그인/관전 정책을 짧게 노출 |
| 첫 방 입장 | 안내 카드가 핵심 행동 전체를 잇지 못함 | 직업 확인부터 결과 화면까지 4단계 체크리스트 제공 |
| 게임 시작 대기 | 맵 이동이나 공격으로 시선이 분산됨 | 직업 공개부터 공격 잠금, 방 중심 카메라 고정 |
| 밤 행동 | 버튼의 의미와 행동 완료 여부가 불명확할 수 있음 | 기존 직업별 화면과 라벨을 유지하고 첫 행동 완료를 계측 |
| 투표 | 첫 투표 전 목표 연결이 약함 | 안내 카드에서 낮 토론과 투표의 관계를 먼저 설명 |
| 사망 후 | 할 일이 없어 이탈하기 쉬움 | 유령 채팅과 관전을 유지하되 비밀 직업은 공개하지 않음 |
| 게임 종료 | 번호만 남아 사람과 정체를 연결하기 어려움 | 참가 번호, 원래 닉네임, 직업, 진영을 함께 공개 |
| 다음 판 | 결과만 보고 방에서 흩어짐 | 개인 복기와 한 판 더 현황을 같은 결과 화면에 제공 |

## 기능 요구사항

- 로비에 현재 접속자 수와 언제든 열 수 있는 게임 방법 버튼을 표시한다.
- 첫 방 입장 시 4단계 안내 카드를 한 번 자동 표시한다.
- 관전자는 단계별 상태와 게임 방법/관전 종료 버튼을 확인할 수 있다.
- 비로그인 사용자는 `비로그인_N` 이름을 사용하고 참가하지 못하며 관전만 가능하다.
- 비로그인 사용자가 이름을 바꿔도 이름 변경 콜백에서 익명 이름을 복구한다.
- 직업 공개 단계부터 모든 참가자와 진행 중 관전자의 기본 공격을 잠근다.
- 같은 시점부터 카메라를 해당 방 중심의 Y+1 타일에 고정한다.
- 게임 종료, 중단, 관전 종료, 대기실 복귀 시 공격과 카메라를 원상복구한다.
- 유령 채팅은 발신자의 직업/진영을 노출하지 않는다.
- 종료 화면은 참가 번호와 원래 닉네임을 함께 표시한다.
- 종료 화면에 본인의 직업/진영/생존 여부와 마지막 행동 두 건만 보여 준다.
- 첫 게임 시작부터 두 번째 게임 시작까지의 퍼널을 개인 식별 정보 없이 한 번씩 계측한다.

## 수용 기준

- 게스트가 빈 방을 누르면 좌석과 관전석 모두 생기지 않고 로그인 확인창이 열린다.
- 게스트가 진행 중인 방을 누르면 좌석 없이 관전석만 생긴다.
- 게임 시작 직후 `disableAttack`은 `true`, 게임 종료 직후 `false`다.
- 1번 방 카메라 목표는 방 중심 Y+1인 `(30, 26)`이다.
- 유령 채팅 payload의 역할과 진영은 빈 값이다.
- 종료 payload의 모든 항목은 `num`과 원래 `name`을 함께 가진다.
- 개인 복기에는 다른 사람의 행동이 섞이지 않는다.
- FTUE payload는 이벤트 allowlist만 포함하며 닉네임, player id, 직업, 대상, 채팅을 포함하지 않는다.
