# 마피아42 역기획 — 우리 게임을 위한 재해석

> 목적: 마피아42를 복제하는 것이 아니라, **왜 재미있는지**를 구조로 분해해서 우리
> ZEP 캐주얼 마피아(6~12인 / 한 판 5~10분 / 텍스트 채팅)에 맞게 다시 조립한다.

**자료 한계 고지.** 참고로 주신 나무위키 두 문서(`마피아42#s-4.2.1`, `마피아42/게임_모드`)는
크롤러 차단(HTTP 403)으로 직접 읽지 못했다. 미러(arca.live, thewiki.kr, theseed.io)도 전부
403/404였다. 그래서 **§1~§3의 마피아42 관련 서술은 검색 스니펫 + 일반 지식 기반**이고,
개별 직업의 최신 시즌 수치(쿨타임, 티어별 강화 내용 등)는 어긋날 수 있다.
확신이 낮은 항목은 `[확인필요]`로 표시했다.

반면 **§4~§8은 전부 우리 코드베이스를 직접 읽고 쓴 것**이라 근거가 확실하다.
문서의 무게중심도 거기에 있다.

## 1. 핵심 게임 분석

### 1.1 왜 마피아42는 오래 인기가 있는가

여섯 가지가 겹쳐 있다. 하나만 빠져도 이 정도로 안 간다.

**(1) 진입 비용이 사실상 0이다.**
규칙이 "밤에 죽이고 낮에 투표한다" 한 줄로 설명된다. 첫 판에 시민을 뽑으면
배울 것이 아예 없다 — 투표만 하면 된다. 다른 게임은 튜토리얼이 필요한데
이 게임은 첫 판이 튜토리얼이다.

**(2) 실력의 천장이 없다.**
같은 규칙인데 상위권은 발언 순서·투표 타이밍·능력 사용 시점으로 논다.
게임이 제공하는 건 규칙이고, 콘텐츠는 사람이 만든다. 그래서 콘텐츠 소진이 없다.

**(3) 절차적 서사 생성기다.**
랜덤 직업 배분 × 랜덤 인원 = 매 판이 다른 이야기. 리텐션의 원천이
"새 콘텐츠 추가"가 아니라 "조합의 곱"이라서 운영 비용 대비 수명이 압도적으로 길다.

**(4) 패배가 재미의 일부다.**
대부분의 게임에서 패배는 마이너스다. 마피아는 **속은 순간이 가장 기억에 남는다.**
"아 저게 마피아였어?"가 다음 판의 동기가 된다. 패배 서사가 리텐션으로 전환되는
장르는 흔치 않다.

**(5) 죽어도 게임이 안 끝난다.**
유령 채팅으로 남는다. 관전이 벌이 아니라 **다른 게임**이다 — "누가 맞추나 보기".
죽은 뒤 이탈이 없으니 방이 안 깨지고, 방이 안 깨지니 다음 판이 바로 돈다.

**(6) 판 안과 판 밖의 성장축이 분리돼 있다.**
판 안은 실력 기반(순수 추리), 판 밖은 시간 기반(루블·카드·스킨). 두 축이 섞이지
않아서 "돈 쓰면 이긴다"는 반발을 어느 정도 흡수한다. (티어 시스템이 이 경계를
넘나드는 것이 마피아42의 가장 큰 밸런스 논쟁거리이기도 하다 — §3에서 다룬다.)

### 1.2 핵심 게임 루프

```
관찰 → 가설 → 발언 → 투표 → 검증 → (정보 갱신) → 반복
```

한 라운드가 만들어내는 것은 정확히 두 가지다.

- **정보 +1단위** (밤 능력 결과 + 사망자 신원 + 투표 기록)
- **인원 −2명** (밤 1 + 낮 1)

게임 전체는 **정보 생산 속도 vs 인원 소모 속도의 경쟁**이다.

- 시민은 정보를 축적해야 이긴다 (선형 증가)
- 마피아는 인원을 줄여야 이긴다 (선형 감소)
- 그런데 **시민의 정보는 사람에게 저장된다.** 마피아가 정보원을 죽이면 축적이 리셋된다.

이 한 문장이 "경찰은 밝히면 죽는다"의 구조적 이유다. 정보를 공개해야 쓸모가 있고,
공개하는 순간 저장소가 파괴된다. **정보 공개 타이밍의 딜레마가 이 게임의 코어**이고,
직업·페이즈·채팅은 전부 이 딜레마를 만들기 위한 장치다.

### 1.3 밤/낮 페이즈의 설계 의도

|         | 밤                     | 낮                      |
| ------- | ---------------------- | ----------------------- |
| 동기성  | 비동기 (각자 결정)     | 동기 (같이 논의)        |
| 공개성  | 비공개                 | 공개                    |
| 의사결정 | 개인                   | 집단                    |
| 기능    | 정보 **생산** + 인원 삭제 | 정보 **유통** + 인원 삭제 |
| 입력    | 클릭 1회               | 문장 N개                |

두 페이즈는 **정보 비대칭을 만드는 장치(밤)와 그것을 거래하는 시장(낮)**이다.
어느 한쪽만 있으면 게임이 성립하지 않는다.

세부 설계 의도 셋:

- **낮이 밤보다 긴 이유** — 밤은 결정(클릭), 낮은 설득(협상). 시간 배분 자체가
  "이 게임은 클릭이 아니라 말로 하는 게임"이라는 선언이다.
- **투표를 낮에서 분리한 이유** — 토론 도중 투표를 허용하면 초반 여론이 그대로 굳는다.
  분리하면 **마지막 30초 발언이 무기**가 되고, 늦게 말하는 것이 전략이 된다.
- **밤이 짧은 이유** — 능력 없는 사람에게 밤은 순수 대기 시간이다. 짧을수록 좋지만
  마피아 협의 시간은 필요하다. 우리 게임의 22초는 이 균형점에 잘 있다.

### 1.4 심리전·정보전·추리 요소

정보에 **3개 층**이 있고, 이게 초보와 숙련자가 같은 판에 앉을 수 있는 이유다.

| 층 | 이름 | 내용 | 필요 실력 |
| --- | --- | --- | --- |
| 1층 | **하드 정보** | 경찰 조사 결과, 밤 사망자, 투표 기록 | 초보도 씀 |
| 2층 | **소프트 정보** | 발언 타이밍, 투표 변경, 침묵, 누가 누구를 방어했나 | 중급 |
| 3층 | **메타 정보** | "저 사람이 나를 마피아로 보고 있다는 것을 내가 안다" → 역이용 | 상급 |

핵심은 **층을 없애지 않고 쌓았다**는 점이다. 1층만 써도 게임이 되고, 3층은 1층 위에
얹힌다. 초보가 상급자의 판에 들어와도 "나는 못 하는 게임"이 아니라
"나는 1층만 쓰는 중"이 된다.

그리고 정보전의 실제 통화(currency)는 **신뢰**이고, 신뢰는 소모품이다.
경찰 커밍아웃 = 쌓아둔 신뢰를 즉시 현금화하고 자기 목숨을 담보로 잡는 행위다.
"언제 현금화할 것인가"가 곧 실력이다.

### 1.5 직업 시스템이 게임에 주는 영향

직업의 기능은 세 가지고, 셋 다 다르다.

1. **역할 부여** — 시민에게 "내가 할 일"을 준다. 능력 없는 시민이 지루한 이유는
   약해서가 아니라 **할 일이 없어서**다.
2. **거짓말의 소재** — 사칭할 대상이 있어야 마피아가 낮에 할 말이 생긴다.
   직업이 마피아/시민 둘뿐이면 마피아의 최적 전략은 침묵이고, 침묵은 콘텐츠가 아니다.
   **직업 수는 마피아의 대사 수와 비례한다.**
3. **카운터 구조** — 가위바위보가 있어야 메타가 순환한다. (§4.5)

그리고 정확히 같은 이유로 **직업은 위험하다.**

직업 수 N이 늘면 경우의 수는 곱으로 늘지만 **초보의 인지 부하도 곱으로 는다.**
"내가 뭘 해야 하지"에서 "쟤가 뭘 할 수 있지"를 외워야 하는 게임으로 변질된다.
마피아42가 티어 시스템으로 이걸 관리한다 — 저티어는 능력이 단순하고, 고티어에서
복잡한 능력이 붙는다. **우리 게임은 단일 티어이므로 다른 관리 수단이 필요하다.**
그래서 §8에서 최종 직업 수를 15개로 끊고, 그중 6개는 "능력이 한 문장으로 끝나는"
직업으로 고정한다.

### 2.4 표에서 읽어야 할 것 — 직업의 5가지 원형

개별 직업을 외우는 것보다 이게 중요하다. 마피아42의 30여 직업은 사실
**5개 원형의 변주**다. 우리 게임의 직업을 설계할 때 이 5칸을 채우면 된다.

| 원형 | 하는 일 | 시민팀 예 | 마피아팀 예 | 이 원형이 없으면 |
| --- | --- | --- | --- | --- |
| **조사자** | 비공개 정보를 하드 정보로 바꾼다 | 경찰, 탐정 | 해커 | 추리가 도박이 된다 |
| **은폐자** | 조사 결과를 오염시킨다 | (없음 — 의도적) | 짐승인간, 사기꾼 | **조사자가 게임을 혼자 끝낸다** |
| **보호자** | 인원 소모 속도를 늦춘다 | 의사, 군인, 경호원 | (없음) | 게임이 3라운드에 끝난다 |
| **집행자** | 인원을 삭제한다 | 자경단원 | 마피아 | 게임이 끝나지 않는다 |
| **교란자** | 남의 능력 결과를 바꾼다 | 판사 | 마담, 마술사 | 밤이 예측 가능해진다 |

**우리 게임의 현재 상태를 이 표에 대보면 결론이 즉시 나온다:**
교란자 칸이 **양쪽 다 비어 있다.** 그래서 밤이 항상 예측 가능하고,
지금 신규 직업을 넣을 때 가장 가치가 큰 칸도 여기다. (§4.3에서 이게
왜 코드 구조상 막혀 있는지 다룬다.)

## 3. 밸런스 분석

### 3.1 필수 직업 (빼면 게임이 무너진다)

| 직업 | 없으면 |
| --- | --- |
| 마피아 | 게임이 아니다 |
| 경찰(조사자) | 낮 토론이 근거 없는 인상 비평이 된다. 초보가 **뭘 해야 할지 모른다** |
| 의사(보호자) | 경찰이 첫 밤에 죽고 게임이 3라운드에 끝난다 |
| 시민(무능력) | 사칭할 배경이 사라진다. **모두가 능력자면 아무도 특별하지 않다** |
| 은폐자 1종 | 경찰이 3턴이면 마피아를 전부 찾는다 (§3.3 참조) |

마지막 줄이 가장 자주 간과된다. **조사자와 은폐자는 세트다.**

### 3.2 없어도 되는 직업

- **순수 정보 소비형** — 결과를 얻지만 그 결과로 할 수 있는 일이 없는 직업.
  (예: 죽은 사람의 직업만 알려주는데 죽은 사람 직업이 이미 공개되는 게임)
- **패시브만 있고 선택이 없는 직업** — 재미의 최소 단위는 "선택"이다.
  군인은 예외적으로 성립한다. 초보 배려용 슬롯으로 **정확히 1개**만 필요하다.
- **상위호환이 존재하는 직업** — 간호사가 있는데 의사가 있다면 간호사는 슬롯 낭비다.
  능력이 아니라 **정보 노출 방식**이 달라야 두 직업이 공존한다.

### 3.3 OP 직업과 그 이유

**(1) 카운터 없는 조사자.**
경찰 1명 + 마피아 M명 + 전체 N명일 때, 랜덤 조사로 T턴에 마피아를 찾을 확률은
대략 `1 - C(N-1-M, T) / C(N-1, T)`. 12인/마피아 3/3턴이면 **약 70%**.
경찰이 3턴을 살면 시민이 이긴다. 그래서 마피아42에 짐승인간이 있고,
우리 게임에도 있다 — 그런데 **우리는 11인부터만 나온다.** (§4.4)

**(2) 부활 계열.**
사망이 되돌려지면 모든 판단의 무게가 절반이 된다. 밸런스보다 **긴장감** 문제다.

**(3) 정보 공개형(기자) 조기 사용.**
1일차에 마피아를 특종하면 그 판은 끝난다. 횟수·타이밍 제한이 필수다.

**(4) 마피아42 고티어 카드 시스템.** `[확인필요]`
같은 직업인데 상대는 강화판이라는 구조는 실력 게임의 전제를 흔든다.
**우리는 단일 티어를 유지한다.** 성장은 판 밖(경험치·칭호)에만 둔다.

### 3.4 저성능 직업과 그 이유

| 유형 | 왜 약한가 | 고치는 법 |
| --- | --- | --- |
| 조건부 발동형 | 조건이 안 오면 판 내내 무능 | 조건 미충족 시의 **대체 행동**을 준다 |
| 후반 특화형 (도굴꾼) | 후반까지 못 산다 | 초반에도 쓸 수 있는 약한 효과를 겸하게 |
| 1회용인데 타이밍이 어려운 형 | 초보가 항상 잘못 쓴다 | 잘못 써도 **정보가 남게** 설계 |
| 무능력 시민 | 할 일이 없다 | 능력이 아니라 **행동거리**를 준다 (§6 시민 개편) |

### 3.5 문제되는 조합

| 조합 | 문제 |
| --- | --- |
| 경찰 + 기자 (은폐자 없음) | 2일차에 마피아 명단 확정. 게임 종료 |
| 의사 + 군인 + 경호원 동시 | 밤 킬이 3연속 무효. **아무 일도 안 일어나는 밤**이 반복되면 이탈 |
| 정치인 + 판사 | 낮 결과를 두 사람이 결정. 나머지 N-2명의 투표가 장식 |
| 자경단원 + 짐승인간 (소인원) | 라운드당 사망 3명. 6인이면 2라운드에 끝 |
| 마담 + 짐승인간 | 조사자가 완전히 무력화. 시민에게 정보 경로가 0 |

### 3.6 메타를 지배하는 조합

숙련자 방에서 실제로 굳는 패턴은 **직업 조합이 아니라 행동 규약**이다.

- **전원 즉시 커밍아웃 메타** — 1일차에 모두가 직업을 선언한다. 마피아는 남은 직업을
  사칭한다. 추리가 "누가 사칭했나"로 축소되고 발언 실력이 사라진다.
  → 대응: **정보 공개에 비용을 붙인다.** 커밍아웃한 사람이 표적이 되도록
  (짐승인간·해커 같은 능동 추적 직업이 그 역할을 한다).
- **침묵 메타** — 말 안 하면 안 걸린다. 낮이 죽는다.
  → 대응: **침묵에 페널티를 주지 말고 발언에 보상을 준다.** (§6 시민·§7 이벤트전)
- **첫 투표 랜덤 처형 메타** — 정보 없는 첫 투표를 그냥 아무나 밀어버린다.
  → 대응: **첫 밤 무사 규칙** (§5.4). 첫 투표 시점에 정보가 1단위 존재하게 만든다.

## 4. 우리 게임에 적용 — 구조 진단 먼저

> 직업 목록부터 쓰지 않는다. **지금 우리 코드가 어떤 직업을 표현할 수 있는지**가
> 제안의 상한이기 때문이다. 이 절이 §5~§8 전체의 근거다.

### 4.0 현재 구조 요약

| 항목 | 현재 값 | 위치 |
| --- | --- | --- |
| 직업 | 12종 | [Roles.ts](src/domain/Roles.ts) |
| 진영 | 2개 (`MAFIA` / `CITIZEN`) | [Game.types.ts](src/types/Game.types.ts) |
| 밤 행동 종류 | 6종 (HEAL/ATTACK/INSPECT_TEAM/INSPECT_ROLE/SILENCE/SCOOP) | [Roles.ts](src/domain/Roles.ts) |
| 페이즈 | 7개, 라운드당 약 106초 | [GameFlow.ts](src/services/GameFlow.ts) |
| 인원 | 4~12인, 8개 방 | [GameConfig.ts](src/constants/GameConfig.ts) |
| 승리 판정 | 2줄 비교 | [WinCondition.ts](src/domain/WinCondition.ts) |

구조는 이미 꽤 좋다. 특히 **`ROLE_DEFS` 한 곳에 직업을 몰아둔 것**과
**`NightResolution`을 순수 함수로 뽑아둔 것**은 정확한 선택이었다.
"직업을 추가할 때 `Night.ts`는 건드리지 않는다"는 [Night.ts:13](src/services/Night.ts:13)의
주석이 실제로 지켜지고 있다.

문제는 **그 표가 표현할 수 있는 직업의 종류**에 천장이 있다는 것이다. 넷이다.

### 4.1 천장 1 — 진영이 이진법이다 (제3세력 불가)

```ts
// src/types/Game.types.ts
export const Team = { MAFIA: "mafia", CITIZEN: "citizen" } as const;
```

```ts
// src/domain/WinCondition.ts
if (alive.mafiaTeam <= 0) return Team.CITIZEN;
if (alive.mafiaTeam >= alive.citizenTeam) return Team.MAFIA;
```

**왜 이렇게 됐나.** 처음엔 이게 옳았다. 진영이 둘뿐이면 승리 판정이 두 줄이고,
`inMafiaChat`·`seatViews`·보상 지급·종료 화면이 전부 `team === MAFIA`
한 번의 비교로 끝난다. 3진법을 미리 만들었다면 쓰지도 않는 분기가 8곳에 생겼을 것이다.

**무엇이 막히나.** 교주·연인·광대처럼 **자기만의 승리 조건**을 가진 직업 전부.
`evaluateWinner`가 `Team | null`을 반환하는 한 "게임은 시민이 이겼는데 광대도 이겼다"를
표현할 수 없다.

**제안 — 진영을 늘리지 말고 승리를 겹치게 한다.**

```ts
// 진영은 그대로 둔다. 게임의 종료 조건은 여전히 2진법이다.
// 개인 승리는 '결과에 얹히는 별도 목록'으로 표현한다.
interface Room {
  // ...
  soloWinners: number[];  // 좌석 index
}
```

`Team`을 3진법으로 바꾸는 것보다 이게 나은 이유:

- **`evaluateWinner`를 안 건드린다.** 두 줄 비교는 검증된 로직이고, 여기를 손대면
  진영 판정·보상·종료 화면·`countAlive`가 전부 회귀 테스트 대상이 된다.
- **광대·연인처럼 "이겨도 게임은 계속되는" 직업이 자연스럽다.** 3진법 진영으로는
  오히려 표현이 어색하다 — 광대는 "진영"이 아니라 "조건"이다.
- **진짜 3파전(교주형 포교)이 필요해지는 순간에만** `Faction` 도입을 하면 된다.
  그때는 `RoleDef`에 `winsWhen: (seats) => boolean`을 다는 것이 답이고,
  `soloWinners`는 그 구조의 부분집합이라 마이그레이션이 자연스럽다.

**대안으로 검토했다가 버린 것:** `Team`에 `NEUTRAL`을 추가하는 것.
`alive.mafiaTeam >= alive.citizenTeam`에서 중립 인원을 어느 쪽으로 셀지가
정의되지 않고, 셋 다 살아있을 때의 종료 조건이 조합 폭발한다. 3파전을 진짜로
하고 싶어질 때까지는 부채다.

### 4.2 천장 2 — 밤이 "선택 즉시 확정"이다 (가장 큰 병목)

```ts
// src/services/Night.ts (bindNightWidget)
const result = resolveNightSelect(seat, target);   // ← 여기서 대상이 즉시 변형된다
label(sender, result.label, result.labelDurationMs); // ← 조사 결과도 즉시 표시
```

`resolveNightSelect`는 **클릭하는 순간** 대상의 `healed`/`attackedBy`/`silenced`를
바꾸고, `INSPECT_TEAM`/`INSPECT_ROLE`은 그 자리에서 답을 돌려준다.
밤이 끝날 때 도는 `resolveNightCasualties`는 이미 확정된 상태를 집계할 뿐이다.

**왜 이렇게 됐나.** 이건 실수가 아니라 **좋은 리팩터링의 결과**다.
[Night.ts](src/services/Night.ts) 상단 주석대로 원래는 직업 이름으로 분기하는
300줄짜리 switch였고, 이걸 "위젯 조립 1벌 + 순수 함수 1개"로 압축하면서
가장 단순한 형태를 골랐다. 그 시점의 6개 능력은 서로 간섭하지 않았으므로
순서가 필요 없었다. **당시엔 옳았다.**

**무엇이 막히나 — 이게 §2.4의 "교란자 칸이 비어 있다"의 진짜 이유다.**

| 만들고 싶은 직업 | 왜 불가능한가 |
| --- | --- |
| 마담 (능력 차단) | 차단하려는 순간 상대는 **이미 클릭해서 이미 결과를 받았다** |
| 사기꾼 (조사 결과 위장) | 경찰의 조사 결과가 이미 화면에 떴다 |
| 마술사 (대상 교체) | 교체 전에 이미 공격이 확정됐다 |
| 도둑 (능력 절취) | 절취 시점에 상대 능력은 이미 소모됐다 |
| 경호원 (대신 죽기) | 공격 확정과 보호 확정의 순서가 클릭 순서에 좌우된다 |

즉 **밤 능력끼리 상호작용하는 직업은 하나도 만들 수 없다.** 지금 12직업이
서로 간섭하지 않는 것은 설계 철학이 아니라 구조의 결과다.

**제안 — 의도(intent)를 모았다가 밤이 끝날 때 순서대로 정산한다.**

```ts
// src/domain/NightPipeline.ts (신규)

/** 정산 순서. 숫자 사이를 비워 둔 것은 나중에 사이에 끼울 수 있게 하기 위함이다 */
export const NightStep = {
  SWAP:    10,  // 대상 교체 (마술사)
  BLOCK:   20,  // 능력 차단 (마담)
  PROTECT: 30,  // 보호 (의사·경호원)
  ATTACK:  40,  // 공격 (마피아·짐승인간·자경단원)
  DEATH:   50,  // 사망 확정 + 자경단원 자책
  INSPECT: 60,  // 조사 (경찰·탐정·해커) — 위장·사망이 반영된 뒤에 답한다
  AFTER:   70,  // 사후 (도굴·특종 공개)
} as const;

export interface NightIntent {
  actor: number;   // 좌석 index
  target: number;
  kind: NightActionKind;
}

/** 밤 종료 시 한 번 호출. 좌석 상태를 여기서만 바꾼다 */
export function resolveNight(
  seats: Seat[],
  intents: readonly NightIntent[]
): { casualties: Casualty[]; reveals: { seat: number; line: string }[] };
```

`RoleDef`에 `nightStep: number` 한 줄이 추가된다. 정산은 step 오름차순, 같은
step 안에서는 좌석 순서(결정적 — [Jint에서 `sort` 안정성을 믿지 않는다는 기존 규칙](README.md)과 일치).

**클릭 즉시 결과가 안 나오는 문제는?** 체감상 문제가 안 된다.
파이프라인은 밤 타이머가 끝나는 시점에 돌고, `reveals`를 **아침 화면을 열기 직전**에
개인 라벨로 뿌리면 된다. 지금도 밤 종료와 아침 사이에 컷이 들어가므로
사용자가 느끼는 지연은 0.5초 미만이다. 대신 얻는 것:

- 교란자 원형 전체가 열린다 (신규 직업 6종의 전제)
- **"내가 지목한 뒤 결과를 기다리는 시간"이 생긴다** — 이건 손해가 아니라 연출이다.
  아침에 결과가 나오는 편이 극적이다.
- 밤 정산이 순수 함수 하나로 모여서 **테스트가 쉬워진다.** 지금은 "마피아가 먼저
  클릭한 경우"와 "의사가 먼저 클릭한 경우"를 재현하려면 위젯 메시지 순서를 흉내내야 한다.

**대안으로 검토했다가 버린 것:** `resolveNightSelect`를 유지하고 특수 직업만
예외 처리하는 것. 정확히 밴드에이드다 — 교란 직업이 하나 늘 때마다 예외가 하나
늘고, 6개쯤 되면 원래의 300줄 switch로 되돌아간다.

### 4.3 천장 3 — 모드 개념이 없다 (게임 모드 불가)

```ts
// src/domain/RoleAssignment.ts
export function buildRoleDeck(playerCount: number, rng = Math.random): Role[]
```

```ts
// src/constants/GameConfig.ts — 모듈 상수. 방마다 다를 수 없다
export const TIMING = { NIGHT: 22, DAY_PER_ALIVE: 10, /* ... */ };
export const MAFIA_RATIO = 0.27;
```

**왜 이렇게 됐나.** 모드가 하나였으니까. 상수를 방 상태로 만드는 것은 모드가
없을 때는 순수한 복잡도 증가다. 옳은 선택이었다.

**무엇이 막히나.** §7의 12개 모드 **전부**. 속도전은 `TIMING`이 달라야 하고,
랜덤 직업전은 `buildRoleDeck`이 달라야 하고, 밴픽전은 직업 풀이 달라야 한다.

**제안 — `RuleSet` 값 객체를 방이 들고 있게 한다.**

```ts
// src/domain/RuleSet.ts (신규)
export interface RuleSet {
  id: string;
  displayName: string;
  timing: typeof TIMING;              // 모드별 페이즈 길이
  mafiaCount: (players: number) => number;
  deck: DeckSpec;                     // 직업 풀·비율·확정 직업
  firstNightPeaceful: boolean;        // §5.4
  nightEvents: boolean;               // §7 이벤트전
}

// Room에 한 줄
interface Room { /* ... */ ruleSet: RuleSet; }
```

기존 `TIMING`/`MAFIA_RATIO`는 `STANDARD_RULES`의 필드가 된다 — **삭제가 아니라 이동**이라
기존 동작이 그대로 보존되고, 방이 하나의 룰셋만 쓰는 동안은 동작이 100% 동일하다.
호출부는 `TIMING.NIGHT` → `room.ruleSet.timing.NIGHT`로 기계적 치환이다.

이 리팩터링의 진짜 가치는 **모드 하나를 추가하는 비용이 "객체 리터럴 하나"가 된다**는
점이다. §7의 12개 모드 중 7개가 `RuleSet` 리터럴만으로 구현된다.

### 4.4 천장 4 — 그 외 표현력 제약 세 가지

**(a) `skillSpent`가 boolean이다.**
```ts
interface Seat { skillSpent: boolean; }  // "판당 1회"만 표현 가능
```
"판당 2회" 능력이 불가능하다. → `skillUses: number`로. `oncePerGame: boolean`도
`maxUses?: number`로 일반화하면 "1회"는 `maxUses: 1`의 특수 케이스가 된다.

**(b) 밤 능력이 "살아있는 대상 1명 지목"으로 고정이다.**
```ts
const target = seatAt(room, targetIndex);
if (!target || !target.alive) return;   // ← 죽은 대상 지목이 원천 차단
```
- 대상 0명(자기 선언형) 표현 불가
- 대상 2명(마술사의 교체, 연인 지정) 표현 불가
- **죽은 사람 지목 불가** → 도굴꾼·성직자가 막힌다

→ `RoleDef`에 `targetKind: "alive" | "dead" | "any" | "none"`과 `targetCount: 0|1|2`.

**(c) `MAFIA_LEAD`가 상수다 — 소인원 밸런스의 숨은 원인.**
```ts
const MAFIA_LEAD: Role = Role.MAFIA;              // 항상 순수 마피아
const MAFIA_POOL = [Role.MAFIA, Role.THUG, Role.BEAST];
```
`nightKillBudget`이 "시민 슬롯 / 4"라서 짐승인간은 **시민 자리가 8이 되는 11인부터**
등장한다. 그런데 짐승인간은 §3.1의 **필수 은폐자**다. 즉 **6~10인 판에는 은폐자가
아예 없고, 경찰이 카운터 없이 돈다.** 이게 소인원에서 시민이 유리한 진짜 이유다.

→ 리드를 풀에서 뽑게 하면(`MAFIA_LEAD_POOL = [MAFIA, BEAST]`) 짐승인간이 마피아를
**대체**하므로 킬 예산이 늘지 않는다. 예산 계산을 "리드 + 추가 킬러"로 다시 정의하면
소인원에서도 은폐자가 등장한다. 코드 변경 ~10줄, 밸런스 효과는 §5 전체.

### 4.5 순환 카운터 설계 — 우리 게임의 4개 링

> 요구사항: "직업 간 카운터 구조가 순환되도록 설계하라."
> 일방향 상성(A가 B를 이긴다)만 있으면 강한 직업이 그냥 강하다.
> **닫힌 고리**를 만들어야 메타가 돈다.

**링 1 — 정보 축 (조사 ↔ 은폐 ↔ 폭로)**

```
   경찰 ──잡는다──▶ 마피아 ──죽인다──▶ 기자
     ▲                                   │
     │                                  잡는다(진짜 직업 공개)
     └────무력화────  사기꾼  ◀───────────┘
```
경찰은 마피아를 잡지만 **사기꾼은 못 잡는다**. 사기꾼은 기자에게 잡힌다.
기자는 밤 킬에 가장 취약하다. 마피아는 경찰에게 잡힌다. **닫힌 고리.**

**링 2 — 보호 축 (보호 ↔ 차단 ↔ 추적)**

```
   의사 ──막는다──▶ 마피아 ──죽인다──▶ 탐정
     ▲                                  │
     │                            방문을 잡는다
     └────능력을 끈다──  마담  ◀─────────┘
```
의사는 마피아 킬을 막고, 마담은 의사를 끄고, 탐정은 마담의 방문 기록을 잡고,
마피아는 탐정을 죽인다. **닫힌 고리.**
(군인의 방탄은 **패시브**라 마담에게 안 걸린다 — 마담이 전능해지지 않게 하는 안전판이다.)

**링 3 — 낮 축 (여론 ↔ 밤 처형 ↔ 방어)**

```
   정치인 ──처형 면역──▶ 낮 투표 무력화
      ▲                        │
      │                  밤에 죽여야 한다
   2표로 몰아냄                 ▼
      │                  자경단원 / 짐승인간
      │                        │
      └───  경호원·군인  ◀──막는다
```
처형이 안 통하는 정치인은 밤 킬로만 제거되고, 밤 킬은 경호원·군인이 막고,
경호원·군인은 정치인의 2표에 밀려 처형될 수 있다. **닫힌 고리.**

**링 4 — 사후 축 (이게 가장 우아하다)**

```
   마피아가 죽인다 ──▶ 시체가 늘어난다 ──▶ 영매·도굴꾼의 정보가 늘어난다
        ▲                                            │
        │                                     마피아가 좁혀진다
        └──── 그래서 마피아는 '죽이지 말고 처형시켜야' 한다 ◀──┘
```
**마피아의 승리 수단(밤 킬)이 스스로의 패배 조건(사후 정보)을 키운다.**
이게 §1.2의 "정보 vs 인원 경쟁"을 직업 레벨로 구현한 것이고, 마피아42의
영매가 실제로 하는 일이다. 우리 게임엔 이미 영매가 있으므로 도굴꾼만 추가하면
링이 완성된다.

**메타 독점 방지 체크:** 위 4개 링에서 어떤 직업도 2개 이상의 링에서 동시에
"카운터 없음" 위치에 있지 않다. 경찰은 링1에서 사기꾼에게, 링2에서 마담에게
막힌다. 마피아는 링1·2·3 모두에서 카운터를 받는다.

## 5. 추천 직업 구성

### 5.1 설계 전제

| 항목 | 값 | 근거 |
| --- | --- | --- |
| 라운드 길이 | 약 100~110초 | 현재 `TIMING` 합계 (밤22+낮~40+투표17+개표7+컷) |
| 목표 판 길이 | 5~10분 | = **3~5라운드** |
| 라운드당 사망 | 2명 (밤1 + 낮1) | 표준 |
| 초보 비율 가정 | 절반 이상 | ZEP 유입 특성 |

**목표 승률: 시민 50±5%.** 정확히 반반이 아니라 시민 쪽을 아주 살짝 높게 두는 것이
캐주얼에서 옳다 — 인원이 많은 쪽이 이기는 판이 체감상 더 만족스럽고,
마피아는 지더라도 "속였다"는 개별 성취가 남기 때문이다.

### 5.2 기본 구성 (6~8인)

**목표: 튜토리얼 구간. 직업 수를 줄이고 규칙 하나만 추가한다.**

| 인원 | 마피아팀 | 시민팀 | 총 특수직 |
| --- | --- | --- | --- |
| 6인 | **1** (마피아 또는 **짐승인간**) | 의사, 경찰, 군인, 시민×2 | 3 |
| 7인 | **2** (마피아 + 사기꾼/건달) | 의사, 경찰, 군인, 시민×2 | 3 |
| 8인 | **2** (마피아 + 사기꾼/건달/짐승인간) | 의사, 경찰, 군인, 영매, 시민×2 | 4 |

**현재 코드와의 차이:** `round(6 × 0.27) = 2`라서 지금 6인은 마피아 2명이다.
이걸 1명으로 낮춘다. 계산해 보면 이유가 분명하다.

> **6인 / 마피아 2 / 시민 4**
> R1 밤 → 시민 3. R1 투표에서 **틀리면** 마피아 2 = 시민 2 → 즉시 마피아 승.
> 즉 **정보가 거의 없는 첫 투표 한 번으로 게임이 끝난다.** 사실상 동전 던지기고,
> 진 초보는 "왜 졌는지"를 배우지 못한다.
>
> **6인 / 마피아 1 / 시민 5 + 첫 밤 무사**
> R1 밤(무사) → 6인 투표. 틀려도 마피아1/시민4. R2 밤 → 시민3.
> R2 투표 틀려도 마피아1/시민3. 최소 **3라운드**, 시민에게 **투표 기회 3번**.
> 한 번만 맞추면 즉시 승리(M=1)라서 마피아 승률은 약 30~35%.

승률 30~35%가 목표(50%)보다 낮은 것은 사실이다. 이걸 **짐승인간 리드**로 메운다
(§4.4c). 6인에서 마피아 1명이 짐승인간이면 경찰의 확정 정보가 사라지고
승률이 45% 근처로 올라온다. 대신 마피아 채팅이 없는데, **어차피 혼자라 채팅이
필요 없다** — 소인원에서만 쓸 수 있는 깔끔한 해법이다.

**예상 플레이 경험 (6인, 초보 방):**
첫 밤에 아무도 안 죽는다 → 전원 생존한 채 첫 토론 → "경찰인데 3번 조사했더니
시민이었다" 한마디로 판이 움직임 → 3~4라운드, 약 5~6분. 초보가
"경찰 말을 믿을지 말지"라는 **딱 하나의 판단**만 하면 되는 구성이다.

### 5.3 일반 구성 (9~10인)

**목표: 표준. 4개 링(§4.5)이 전부 등장하는 최소 인원.**

| 인원 | 마피아팀 (2) | 시민팀 |
| --- | --- | --- |
| 9인 | 마피아 + [사기꾼/건달/마담] 중 1 | 의사, 경찰, 군인, 영매, 정치인, 시민×2 |
| 10인 | 마피아 + [사기꾼/건달/마담/짐승인간] 중 1 | 의사, 경찰, 군인, 영매, 탐정, 자경단원, 시민×2 |

첫 밤 무사 규칙은 **적용하지 않는다.** 9인이면 라운드가 이미 4~5회 확보된다.

**예상 승률:** 시민 52 / 마피아 48. 마피아 2번째 슬롯이 랜덤이라
"오늘은 은폐자냐 교란자냐"에 따라 시민의 최적 전략이 달라진다.

**예상 플레이 경험:**
경찰이 2일차에 커밍아웃 → 의사가 붙는다 → 마담이 의사를 끈다 → 경찰이 죽는다 →
영매가 유령 채널에서 경찰의 마지막 정보를 회수한다. **정보가 사람에서 사람으로
넘어가는 흐름**이 한 판 안에서 관찰된다. 이게 우리가 팔아야 할 경험이다.

### 5.4 풀방 구성 (11~12인)

**목표: 숙련자. 정보량이 많고 라운드가 길다.**

| 인원 | 마피아팀 (3) | 시민팀 |
| --- | --- | --- |
| 11인 | 마피아×2 + [짐승인간/마담/사기꾼] 중 1 | 의사, 경찰, 군인, 영매, 정치인, 탐정, 기자, 시민×1 |
| 12인 | 마피아×2 + [짐승인간/마담/사기꾼/건달] 중 1 | 의사, 경찰, 군인, 영매, 정치인, 탐정, 기자, 자경단원, 시민×1 |

**시민(무능력)을 1명은 반드시 남긴다.** §3.1의 이유 — 전원이 능력자면 아무도
특별하지 않고, 마피아가 사칭할 "평범한 배경"이 사라진다.

**12인 라운드 계산:** 마피아 3 / 시민 9. 시민이 매번 맞춰도 3라운드, 매번 틀리면
`(9-3)/2 = 3`라운드. **어느 쪽이든 3~5라운드 = 5~9분.** 목표에 정확히 들어간다.
현재 `MAFIA_RATIO = 0.27`이 12인에서 3명을 주는 것은 그대로 옳다.

**예상 플레이 경험:**
12명이 동시에 말하면 텍스트 채팅이 흐른다 — 이게 우리 게임의 **최대 리스크**다.
그래서 풀방에는 기자(직업 확정 공개)를 넣어 **논의의 앵커**를 준다.
"기자가 5번을 특종했다"는 한 줄이 흐르는 채팅에 고정점을 만든다.

### 5.5 첫 밤 무사 규칙 (`firstNightPeaceful`)

6~8인에만 적용. 마피아는 첫 밤에 지목을 하지만 **아무도 죽지 않는다**
(대신 마피아 채팅으로 팀을 확인한다). 경찰·의사 등 다른 능력은 정상 작동한다.

**얻는 것:** 첫 투표 시점에 정보가 1단위 존재한다. 첫 투표가 동전 던지기에서
"경찰의 첫 조사 결과를 믿을 것인가"로 바뀐다.

**버린 대안:** *처형에 과반 요구.* 정보 없는 첫 투표가 자동 무산되어 같은 효과를
내지만, 초보에게 "왜 아무도 안 죽었지?"라는 설명하기 어려운 상황이 매 판 생긴다.
첫 밤 무사는 규칙이 한 문장이고 딱 한 번만 일어난다.

**구현 비용:** `RuleSet.firstNightPeaceful` + `resolveNight`에서
`turnCount === 0 && ruleSet.firstNightPeaceful`이면 ATTACK step을 건너뛴다. ~5줄.

## 6. 신규 직업 제안 (12종)

각 직업의 **[구조]** 항목은 §4의 어느 천장을 먼저 뚫어야 하는지를 가리킨다.
그게 이 목록의 개발 순서다.

---

### 6-1. 사기꾼 (CON_ARTIST) · 마피아팀

| | |
| --- | --- |
| **능력** | 경찰 조사에 **"마피아가 아님"**으로 나온다. 그리고 조사당한 날 아침에 **"어젯밤 누군가 당신을 조사했다"**를 본다 (누구인지는 모른다). 밤 킬 없음 |
| **타이밍** | 상시 패시브. 밤에 할 일 없음 (마피아 채팅 참여) |
| **카운터** | 기자(특종하면 진짜 직업 공개) / 영매(사후 진실) |
| **카운터하는 것** | 경찰 |
| **[구조]** | 4.2 파이프라인 (INSPECT step에서 위장 상태를 읽어야 함) |

**기획 의도.** §3.1의 **필수 은폐자**를 소인원에 공급한다. 짐승인간은 킬이 하나 더
늘어서 6~10인에 못 넣지만(§4.4c), 사기꾼은 **밤 킬 예산을 먹지 않으므로 7인부터
넣을 수 있다.** 링 1의 시작점이다.

"조사당한 사실을 안다"는 강도가 정확히 맞다. **누가** 조사했는지 알면 경찰을 찾아
죽일 수 있어 과하고, 아무것도 모르면 그냥 수동 직업이라 심심하다. "경찰이 살아있고
나를 클리어로 찍었다"는 정보는 마피아 채팅에 흘릴 값어치가 있으면서
그 자체로 경찰을 죽이지는 못한다.

**예상 플레이 경험.** 사기꾼은 낮에 **당당하다.** "경찰 있으면 나 조사해봐"라고
먼저 말할 수 있는 유일한 마피아다. 그리고 조사당한 다음 날 "어제 조사 나 받았는데
왜 아무 말 없냐"고 되물어 경찰의 커밍아웃을 강제할 수 있다. **마피아가 공격적으로
말할 수 있는 직업**이라 침묵 메타(§3.6)를 직접 깬다.

**밸런스 위험.** 짐승인간과 동시 등장하면 경찰이 완전 무력화된다.
→ **덱 규칙: 사기꾼과 짐승인간은 같은 판에 함께 나오지 않는다.**

### 6-2. 마담 (MADAM) · 마피아팀

| | |
| --- | --- |
| **능력** | 밤에 1명을 지목해 **그 사람의 밤 능력을 무효화**한다. 대상은 아침에 "간밤에 아무 일도 없었다"만 본다 |
| **타이밍** | 매 밤. 자기 자신·마피아 팀원 지목 불가 |
| **카운터** | 탐정(방문 기록에 잡힘) / 군인·정치인(패시브라 안 걸림) |
| **카운터하는 것** | 의사, 경찰, 자경단원, 기자 |
| **[구조]** | 4.2 파이프라인 (BLOCK step) — **이 직업 없이는 파이프라인의 가치가 절반이다** |

**기획 의도.** §2.4의 비어 있는 **교란자** 칸을 마피아 쪽에서 채운다.
마피아의 유일한 "죽이지 않는 승리 수단"이다.

**중요한 안전판:** 마담은 **능동 능력만** 끈다. 군인의 방탄, 정치인의 처형 면역 같은
패시브는 못 막는다. 이게 없으면 마담이 전능해진다. (§4.5 링 2에 명시)

**예상 플레이 경험.** 의사가 "나 어제 3번 지켰는데 3번이 죽었다"고 말하는 순간
마담의 존재가 드러난다. **시민 쪽에 "우리 중에 방해꾼이 있다"는 새 가설이 생긴다.**
지금 우리 게임엔 밤에 실패할 방법이 없어서 이 대사가 나올 수 없다.

**밸런스 위험.** 매 밤 확정 무효화는 세다. 특히 마담+짐승인간이면 시민의 정보 경로가
0이 된다(§3.5).
→ **덱 규칙: 마담은 마피아팀 인원이 2명 이상일 때만.** + **짐승인간과 동시 등장 금지.**
→ 필요하면 `maxUses: 3`으로 제한 (§4.4a의 카운터가 필요한 이유).

### 6-3. 해커 (HACKER) · 마피아팀

| | |
| --- | --- |
| **능력** | 밤에 1명을 지목하면 **그 사람이 이번 밤에 누구를 지목했는지** 알아낸다. 능력이 없거나 지목하지 않았으면 "아무것도 하지 않았다" |
| **타이밍** | 매 밤 |
| **카운터** | 마술사(교체된 대상이 보임) / 밤 킬 |
| **카운터하는 것** | 경찰, 의사 (능동 직업의 정체를 추적) |
| **[구조]** | 4.2 파이프라인 (INSPECT step, 다른 intent를 읽어야 함 — **파이프라인 없이는 절대 불가**) |

**기획 의도.** 마피아에게 **조사자**를 준다. 지금 마피아는 정보를 얻는 수단이 전혀
없어서 "누구를 죽일까"가 감이다. 해커가 있으면 마피아의 밤 선택에 근거가 생긴다.

그리고 §3.6의 **즉시 커밍아웃 메타를 직접 처벌한다.** 능동적으로 움직이는 사람이
잡히므로, "능력자는 조용히 있는 게 낫다"는 반대 압력이 생긴다.

**예상 플레이 경험.** "5번이 어젯밤 2번을 봤다" → 5번은 조사자나 보호자다 →
다음 밤 5번을 죽인다. **마피아의 밤이 도박에서 사냥으로 바뀐다.**

**밸런스 위험.** 마피아 정보력이 과해진다. → 마담과 **동시 등장 금지**
(둘 다 능동 직업 저격이라 겹친다). 12인 전용으로 제한하는 것도 검토.

### 6-4. 탐정 (DETECTIVE) · 시민팀

| | |
| --- | --- |
| **능력** | 밤에 1명을 지목하면 **그 사람이 이번 밤에 몇 번 지목당했는지** 안다 (0 / 1 / 2회 이상) |
| **타이밍** | 매 밤 |
| **카운터** | 마담(차단) / 밤 킬 |
| **카운터하는 것** | 마담, 마피아 (방문의 흔적을 잡는다) |
| **[구조]** | 4.2 파이프라인 (INSPECT step) |

**기획 의도.** 해커의 **대칭**이다. 해커는 "누구를 봤나"(능동), 탐정은
"몇 번 찍혔나"(수동). 같은 정보 공간을 반대 방향에서 본다.

정보의 성질도 다르다 — 경찰은 **하드 정보**(1층)를 주지만 탐정은
**해석이 필요한 정보**(2층)를 준다. "2번이 어젯밤 2번 찍혔다"는 것은
공격+보호일 수도, 공격 2회일 수도, 조사 2회일 수도 있다.
**초보는 못 쓰고 숙련자는 강하게 쓰는 직업**이 하나 필요하다.

**예상 플레이 경험.** "어제 7번이 두 번 찍혔는데 안 죽었다" → 의사가 붙었거나
군인이다 → 7번은 시민 확정에 가깝다. **경찰 없이도 클리어를 만들 수 있는 두 번째
경로**가 생긴다. 경찰 의존도가 낮아져 링 1의 순환이 강해진다.

**밸런스 위험.** 낮음. 정보가 애매해서 혼자 판을 끝내지 못한다.
오히려 초보가 잘못 해석해 오처형을 유도할 위험이 있는데, 그건 **버그가 아니라 기능**이다.

### 6-5. 경호원 (BODYGUARD) · 시민팀

| | |
| --- | --- |
| **능력** | 밤에 1명을 경호. 그 사람이 공격받으면 **경호원이 대신 죽고 대상은 산다** |
| **타이밍** | 매 밤. 자기 자신 지목 불가 |
| **카운터** | 마담(차단) |
| **카운터하는 것** | 마피아, 짐승인간, 자경단원 |
| **[구조]** | 4.2 파이프라인 (PROTECT/ATTACK 순서가 확정되어야 함) |

**기획 의도.** 의사와 능력이 겹치는 것처럼 보이지만 **비용 구조가 정반대**다.

|  | 의사 | 경호원 |
| --- | --- | --- |
| 비용 | 없음 | **자기 목숨** |
| 정보 노출 | "누군가 살았다"만 (익명) | **경호원이 죽어서 공개됨** |
| 반복 가능 | 매 밤 | 한 번 발동하면 끝 |

§3.2의 "능력이 아니라 정보 노출 방식이 달라야 두 직업이 공존한다"의 실례다.
의사는 조용히 지키고, 경호원은 **자기 죽음으로 "여기 공격이 있었다"를 확정 증명한다.**

**예상 플레이 경험.** 경호원이 죽는 순간 시민 전체가 "3번이 마피아 표적이었다 =
3번은 시민 확정 + 3번이 중요한 직업"을 동시에 안다. **한 명의 죽음이 두 개의
정보를 만드는 유일한 순간**이라 극적이다.

**밸런스 위험.** 의사+군인+경호원이 겹치면 밤이 3연속 무효(§3.5).
→ **덱 규칙: 보호 계열(의사·군인·경호원)은 최대 2종까지.**

### 6-6. 도굴꾼 (GRAVEDIGGER) · 시민팀

| | |
| --- | --- |
| **능력** | 밤에 **죽은 사람 1명**을 지목해 그 직업을 알아낸다 |
| **타이밍** | 2일차 밤부터 (첫 밤엔 시체가 없다) |
| **카운터** | 마담(차단) / 밤 킬 |
| **카운터하는 것** | 마피아의 밤 킬 전략 전체 |
| **[구조]** | 4.4b (죽은 대상 지목 — 현재 `!target.alive` 에서 차단됨) |

**기획 의도.** §4.5 **링 4(사후 축)**를 완성한다. 우리 게임에서 죽은 사람의 직업은
[종료 화면에서만 공개](src/services/Death.ts:57)되고, 처형 시에도 "마피아 팀이었다 /
아니었다"만 알린다. 즉 **밤에 죽은 사람의 직업은 아무도 모른다.** 이게 도굴꾼에게
줄 수 있는 정보가 실제로 존재한다는 뜻이다.

**밤 킬이 늘수록 도굴꾼의 정보가 늘어난다** → 마피아는 죽일수록 불리해진다 →
마피아는 처형을 유도해야 한다 → 낮 축(링 3)으로 넘어간다. 링이 링을 부른다.

**예상 플레이 경험.** 후반 캐리 직업이다. 3일차쯤 "어제 죽은 4번이 의사였다"를
공개하면 "그럼 지금 의사라고 하는 놈은 마피아"가 즉시 확정된다.
**사칭을 사후에 파괴하는 유일한 수단.**

**밸런스 위험.** §3.4의 "후반 특화형은 후반까지 못 산다".
→ 완화: 도굴꾼은 **자기 직업이 조사에 시민으로 잡히지 않는다** 같은 보정 대신,
**시체가 3구 이상이면 하룻밤에 2구를 볼 수 있게** 한다. 후반 가치를 더 올리는 게
아니라 후반 **도달 확률**을 올려야 하므로, 실은 **9인 이상에서만 배치**하는 것이
가장 싼 해법이다.

### 6-7. 성직자 (PRIEST) · 시민팀

| | |
| --- | --- |
| **능력** | 판당 1회, 밤에 **죽은 사람 1명을 부활**시킨다. 부활한 사람의 **직업이 전체 공개**된다 |
| **타이밍** | 2일차 밤부터, 1회 |
| **카운터** | 마담(차단) / 마피아를 부활시키는 자멸 |
| **카운터하는 것** | 오처형 |
| **[구조]** | 4.4b (죽은 대상) + 4.2 (AFTER step) |

**기획 의도.** §3.3에서 "부활은 OP"라고 썼다. 그래서 **직업 전체 공개를 대가로 붙인다.**
- 시민을 부활시키면: 시민 +1 **그리고 그 사람의 직업이 확정 공개** → 시민 대승
- 마피아를 부활시키면: **마피아 +1인데 정체가 공개됨** → 마피아는 살아났지만 다음 낮에
  확정 처형. 실질 손익은 시민에게 미미한 플러스

즉 **부활 자체가 도박이 아니라, 부활이 곧 도굴이다.** 정보와 인원 중 하나는 반드시
얻는다. 이게 "부활은 긴장을 죽인다"는 문제를 우회하는 방식이다 —
**되돌리는 게 아니라 정보로 환전한다.**

**예상 플레이 경험.** "누구를 살릴까"가 판 전체의 이벤트가 된다. 유령 채널에서
죽은 사람들이 자기를 살려달라고 어필하는 장면이 나온다. **죽은 사람에게 발언
동기를 주는 유일한 직업.**

**밸런스 위험.** 12인 전용. 소인원에서 인원 +1은 승패를 직접 뒤집는다.

### 6-8. 점쟁이 (SEER) · 시민팀

| | |
| --- | --- |
| **능력** | **첫 밤에만** 1명을 지목해 **"밤에 쓸 능력이 있는가"**를 안다 (진영은 모른다) |
| **타이밍** | 첫 밤 1회. 이후 무능력 |
| **카운터** | 정보가 약해서 카운터가 불필요 |
| **카운터하는 것** | 첫날의 정보 공백 |
| **[구조]** | 4.4a (`maxUses`) — 나머지는 현재 구조로 구현 가능 |

**기획 의도.** §3.6의 **첫 투표 랜덤 처형 메타**를 정면으로 노린다.
"첫 밤 무사"(§5.5)와 짝을 이룬다 — 첫 밤에 아무도 안 죽는 대신, 첫 투표에
**약한 정보 한 조각**은 존재하게 한다.

정보 강도가 정교하게 약하다. "능력이 있다"는 마피아일 수도 경찰일 수도 있다.
**혼자서는 아무것도 확정하지 못하지만 토론의 시작점은 된다.** 첫날 침묵을 깨는
용도로 딱 맞다.

**예상 플레이 경험.** "1번은 능력이 없다"는 한 줄로 첫 토론이 시작된다.
그리고 점쟁이는 2일차부터 완전 무능력이라 **자기가 시민인 척 살아남아야 한다** —
말한 뒤엔 그냥 표적이 되므로 "언제 말할까"가 유일한 선택이다. 능력은 1회지만
판단은 판 내내 이어진다.

**밸런스 위험.** 거의 없음. §3.4의 "1회용인데 타이밍이 어려운 형"에 해당하지만
잘못 써도 정보가 남는 형태라 초보에게 안전하다.

### 6-9. 판사 (JUDGE) · 시민팀

| | |
| --- | --- |
| **능력** | 판당 1회, 개표 직후 **그날의 처형을 무효화**한다. 누가 썼는지는 공개되지 않는다 |
| **타이밍** | 낮 (개표 화면) |
| **카운터** | 마피아의 여론 조작 (판사가 카드를 쓰게 유도) |
| **카운터하는 것** | 오처형, 정치인의 2표 |
| **[구조]** | 낮 페이즈 훅 — 현재 구조로 구현 가능 (`VOTE_RESULT` 진입 전 개입) |

**기획 의도.** §4.5 **링 3(낮 축)**에서 정치인의 카운터. 정치인은 자기를
지키고 판사는 남을 지킨다. 그리고 지금 우리 게임의 낮에는 **투표 외의 선택이
하나도 없다** — 낮 페이즈의 유일한 능동 능력이다.

**익명 발동**이 중요하다. 공개되면 판사가 즉시 표적이 되고, "안 쓰는 게 최선"이
되어 능력이 죽는다. 익명이면 시민 전체가 "판사가 아직 있나?"를 계속 궁금해한다.

**예상 플레이 경험.** 확신 없는 처형이 무산되는 순간 방 전체가 술렁인다.
"누가 막았지?" → **마피아도 판사가 누군지 모른다.** 그리고 판사는 카드를 쓴 뒤에도
"안 썼다"고 말할 수 있다. 3층 메타 정보(§1.4)가 생기는 지점이다.

**밸런스 위험.** 처형이 무산되면 그 라운드의 인원 감소가 절반이 되어 게임이 길어진다.
→ **1회 제한 필수.** 10인 이상에서만 배치.

### 6-10. 마술사 (MAGICIAN) · 시민팀

| | |
| --- | --- |
| **능력** | 밤에 **2명**을 지목해 자리를 바꾼다. 그날 밤 그 둘을 향한 모든 지목이 **서로 뒤바뀐다** |
| **타이밍** | 판당 1회 |
| **카운터** | 마담(차단) / 자기 실수 |
| **카운터하는 것** | 마피아의 밤 킬, 경찰 조사, 의사 보호 — **전부** |
| **[구조]** | 4.4b (대상 2명) + 4.2 (SWAP step, 가장 먼저) |

**기획 의도.** §2.4의 **교란자**를 시민 쪽에서 채운다. 마담의 시민판 대칭이지만
성격이 다르다 — 마담은 **끄고**, 마술사는 **섞는다.**

우리 게임에서 가장 어려운 직업이 될 것이고, **의도적이다.** §1.5에서
"12~16개 선에서 끊는다"고 했지만 숙련자용 최상위 난이도 슬롯이 하나는 필요하다.
숙련자에게 "이 직업 뽑히면 오늘 재밌겠다"는 대상이 있어야 한다.

**예상 플레이 경험.** 마피아가 3번을 죽였는데 7번이 죽는다. 경찰이 3번을 조사했는데
7번의 결과를 받는다. **밤 전체가 한 번 뒤집힌다.** 마피아는 다음 날
"우리가 죽인 사람이 안 죽었다"를 마피아 채팅에서 확인하고 패닉한다.

**밸런스 위험.** 크다. 아군을 죽일 수 있고, 경찰의 조사 결과를 오염시켜
**시민 전체를 잘못된 결론으로 몰 수 있다.** 그래서 판당 1회, 12인 전용.
그리고 마술사 본인에게는 "누가 뒤바뀐 결과를 받았는지"를 알려주지 않는다 —
본인도 결과를 모르는 게 이 직업의 재미다.

### 6-11. 운명 (BOUND / 연인) · 진영 유지 · 2인 1조

| | |
| --- | --- |
| **능력** | 2명이 짝으로 묶인다. **서로의 직업을 안다.** 한쪽이 죽으면 다른 쪽도 함께 죽는다 |
| **타이밍** | 게임 시작 시 배정. 능동 능력 없음 |
| **카운터** | 짝이 마피아면 딜레마 / 짝을 잃으면 즉사 |
| **카운터하는 것** | 진영 논리 |
| **[구조]** | 4.1 (`soloWinners` **불필요** — 진영을 유지하므로 현재 구조로 구현 가능) |

**기획 의도.** 이게 §4.1에서 "진영을 늘리지 않고" 설계한 이유의 실례다.
마피아42의 연인처럼 제3세력을 만들지 않는다. **각자 원래 진영 그대로 승리를 노린다.**
그런데 짝이 죽으면 같이 죽는다.

여기서 나오는 상황이 압권이다: **시민이 마피아와 묶이면**, 그 시민은
- 짝이 마피아인 걸 **안다**
- 하지만 짝을 처형시키면 **자기도 죽는다**
- 짝이 살아야 자기가 사는데, 짝이 이기면 자기는 진다

"이기고 싶은데 그러려면 죽어야 한다"는 완전한 딜레마다. 제3세력 없이
**승리 조건과 생존 조건을 분리**하는 것만으로 이만한 긴장이 나온다.

**예상 플레이 경험.** 마피아와 묶인 시민의 최적 플레이는
"짝을 지키면서 다른 마피아를 잡는 것"이다. 그래서 이 시민은 특정인을 계속
변호하는데, 그게 남들 눈엔 **마피아 짝패로 보인다.** 억울한데 해명할 수가 없다.
이 게임에서 만들 수 있는 가장 좋은 이야기 중 하나다.

**밸런스 위험.** 소인원에서 동반 사망은 인원 −2라 라운드가 급감한다.
→ **10인 이상 전용.** 그리고 §7의 듀오전에서는 이게 기본 규칙이 된다.

### 6-12. 시민 (CITIZEN) 개편 — 신규는 아니지만 가장 중요하다

| | |
| --- | --- |
| **현재** | 능력 없음. 밤에 대기 |
| **제안** | 밤에 **1명에게 익명 쪽지 1줄**을 보낼 수 있다 (판당 1회, 발신자 미표시) |

**기획 의도.** §3.1에서 "무능력 시민은 필수"라고 썼고 §3.4에서 "할 일이 없다"고 썼다.
둘 다 맞다. 해법은 **정보 능력을 주지 않으면서 행동거리를 주는 것**이다.

익명 쪽지는 정보를 **생산하지 않는다.** 시민은 여전히 아는 게 없다.
하지만 **유통**은 할 수 있다. 그리고 이건 게임을 바꾼다:

- 경찰이 커밍아웃하지 않고 **쪽지로만** 정보를 전달할 수 있다 → 정보 공개
  딜레마(§1.2)에 세 번째 선택지가 생긴다
- 마피아도 쪽지를 쓸 수 있으므로 **쪽지를 믿을 수 없다** → 정보 오염이
  플레이어 손에서 발생한다. 시스템이 만든 거짓말이 아니라 사람이 만든 거짓말
- 시민이 밤에 **뭔가 한다**

**예상 플레이 경험.** "나 경찰인데 3번이 마피아야. 아침에 네가 말해줘."
받은 사람은 이게 진짜 경찰인지 마피아의 함정인지 모른다. 말하면 자기가 표적이 되고,
안 말하면 정보가 사라진다. **무능력 시민이 판의 중심에 서는 순간**이 생긴다.

**밸런스 위험.** 채팅 남용. → 판당 1회, 1줄, 길이 제한.
[기존 채팅 레이트리밋](src/constants/GameConfig.ts) 인프라를 그대로 쓴다.
그리고 신고/차단이 이미 있으므로 익명 쪽지도 신고 대상에 포함시킨다.

### 7-2. 속도전 (Blitz) — ★

| | |
| --- | --- |
| **규칙** | 밤 12초 / 낮 25초 / 투표 10초 / 개표 4초. 직업 풀 축소(마피아·의사·경찰·군인·시민만). 첫 밤 무사 |
| **인원** | 6~8인 |
| **시간** | **3~4분** |
| **난이도** | ★ (`RuleSet.timing` + `deck` 리터럴) |

**재미 포인트.** 생각할 시간이 없어서 **직감으로 던진다.** 오히려 초보가
숙련자와 대등해지는 유일한 모드다 — 숙련자의 무기(긴 논리, 발언 순서 조작)가
시간에 막힌다.

**기획 의도.** 모바일 대응. ZEP은 이동 중 접속이 많고, 5~10분도 긴 경우가 있다.
그리고 **첫 판 유입용**으로 최적이다. 3분이면 "한 판만 더"가 나온다.

### 7-3. 이벤트전 (Chronicle) — ★★ **1순위 추천**

| | |
| --- | --- |
| **규칙** | 매 밤 시작 시 무작위 이벤트 1개가 방 전체에 공지된다 |
| **인원** | 8~12인 |
| **시간** | 6~10분 |
| **난이도** | ★★ (이벤트 테이블 + 정산 파이프라인의 훅) |

**이벤트 예시 (초기 8종):**

| 이벤트 | 효과 | 노리는 것 |
| --- | --- | --- |
| 🌫️ 짙은 안개 | 오늘 밤 모든 **조사가 실패**한다 | 경찰 의존 메타 파괴 |
| 🕯️ 정전 | 오늘 낮 채팅이 **전원 익명**으로 표시된다 | 발언 실력만 남긴다 |
| ⚖️ 계엄령 | 오늘 처형은 **2명**이다 | 게임 가속, 소극적 플레이 처벌 |
| 🕊️ 휴전 | 오늘 밤 **아무도 죽지 않는다** | 정보 축적 라운드 |
| 🔍 감사 | 오늘 밤 **사망자의 직업이 공개**된다 | 사후 정보 폭발 |
| 🗳️ 만장일치 | 오늘 처형은 **과반 이상**일 때만 집행된다 | 신중한 투표 강제 |
| 💰 현상금 | 어제 최다 득표자를 죽인 쪽에 **정보 1개** 제공 | 표적 유도 |
| 🔇 봉쇄 | 오늘 낮 **각자 3줄까지만** 발언 가능 | 말의 밀도를 올린다 |

**재미 포인트.** **매 밤 규칙이 바뀐다.** 외운 전략이 안 통해서 숙련자의
우위가 줄고, 초보에게는 "오늘은 무슨 일이 일어날까"라는 별개의 기대가 생긴다.

**기획 의도.** 개발 비용 대비 체감 신규성이 가장 높다. 직업 하나 추가하는 것보다
이벤트 8개 추가가 싸고, 시즌마다 이벤트를 갈아끼우면 **콘텐츠 갱신 비용이
거의 0**이다. 그리고 §4.2 파이프라인이 있으면 대부분의 이벤트가
"특정 step을 건너뛴다" 한 줄이다.

### 7-4. 랜덤 직업전 (Chaos) — ★

### 7-5. 듀오전 (Duo) — ★★

| | |
| --- | --- |
| **규칙** | 2인 1조로 입장. **짝은 서로의 직업을 안다.** 승리 조건은 각자의 진영 |
| **인원** | 8·10·12인 (짝수) |
| **시간** | 6~10분 |
| **난이도** | ★★ (로비 페어링 + 역할 카드에 짝 정보) |

**재미 포인트.** §6-11 운명의 모드판이다. 다만 **동반 사망은 없다** — 그건 랜덤
페어링(운명전) 쪽에 둔다. 친구와 들어왔는데 한쪽이 마피아면 그 순간부터

**초보에게 붙는 멘토**이기도 하다 — 숙련자 친구가 옆에서 알려줄 수 있다.

**변형 — 운명전 (Fate):** 짝을 **랜덤으로** 묶고 동반 사망을 켠다.
친구 동반이 아니라 "누구랑 묶였는지 모른다"가 재미. 개발 비용은 같다.

### 7-6. 숨은 배신자 (Turncoat) — ★★

| | |
| --- | --- |
| **규칙** | 시민 중 1명이 **2일차 밤에 마피아로 전향**한다. 본인은 처음부터 알고, 마피아는 전향 시점에 안다 |
| **인원** | 9~12인 |
| **시간** | 6~10분 |
| **난이도** | ★★ (스파이의 `defectsToMafia` 재활용) |

**재미 포인트.** 배신자의 최적 플레이는 **초반에 진짜 시민처럼 활약해서 신뢰를 쌓는 것**이다.
목표가 한 문장이라 초보도 즉시 이해한다. 그리고 시민 입장에서는
"1일차의 클리어가 3일차엔 클리어가 아니다" — **모든 확정 정보에 유통기한이 생긴다.**

**기획 의도.** 우리 게임의 스파이(`defectsToMafia`)가 이미 반쪽 구현이다.
차이는 **조건**이다 — 스파이는 마피아를 *찾아야* 합류하고, 배신자는 *시간이 되면*
자동 합류한다. 후자가 초보에게 훨씬 쉽고 확정적이다.

그리고 밴 통계가 **실전 밸런스 지표**로 직결된다 — 밴율 1위 직업이 다음 패치 대상이다.

### 7-8. 거짓 정보전 (Fog of War) — ★★

| | |
| --- | --- |
| **규칙** | 모든 조사 결과가 **20% 확률로 뒤집힌다.** 본인은 뒤집혔는지 모른다 |
| **인원** | 10~12인 |
| **시간** | 8~12분 |
| **난이도** | ★★ (INSPECT step에 확률 플립) |

**재미 포인트.** **확실한 정보가 사라진다.** 경찰 커밍아웃이 "확정"이 아니라
"80% 확신"이 되고, 잘못된 조사 결과를 들고 확신하는 경찰이 시민을 학살한다.
1층 하드 정보가 2층 소프트 정보로 강등되는 모드.

**기획 의도.** 숙련자 전용 하드코어 슬롯. 그리고 **초보에게는 절대 노출하면 안 되는
모드**라 별도 방으로 격리한다. 명확한 경고 표시 필수.

**주의.** 확률이 20%인 게 중요하다. 50%면 정보가 무의미해지고, 10%면 체감이 없다.
20%는 "5번 중 1번" — 판당 한 번쯤 어긋나는 빈도다.

### 7-9. 전원 특수직 (All-Star) — ★

| | |
| --- | --- |
| **규칙** | 무능력 시민 0명. 전원이 능력을 갖는다 |
| **인원** | 8~10인 |
| **시간** | 4~7분 (정보 밀도가 높아 빨리 끝난다) |
| **난이도** | ★ (`deck` 리터럴) |

**재미 포인트.** 매 밤 8개 능력이 동시에 발동한다. **밤이 시끄럽다.**
그리고 사칭할 배경(시민)이 없어서 마피아가 **반드시 특수직을 사칭해야 한다** —
사칭이 훨씬 위험해진다.

**기획 의도.** §3.1의 "무능력 시민 필수"를 **일부러 위반하는 모드**다.
필수 규칙이 왜 필수인지를 유저가 체감하게 만드는 것도 가치가 있고,
실제로 재밌을 것이다(정보 과잉 자체가 카오스다). 랭크 미반영.

### 8.3 시즌 로드맵

> **원칙: 매 시즌 "직업 N개"가 아니라 "구조 1개 + 그 위의 콘텐츠"를 낸다.**
> 구조 없이 직업만 쌓으면 §4.2의 300줄 switch로 되돌아간다.

---

**시즌 0 — 구조 정비 (콘텐츠 0개)**

| 작업 | 내용 | 근거 |
| --- | --- | --- |
| `RuleSet` 도입 | `TIMING`·`MAFIA_RATIO`·덱 스펙을 `Room.ruleSet`으로 이동 | §4.3 |
| 밤 파이프라인 | `resolveNightSelect` → intent 수집 + `resolveNight` 정산 | §4.2 |
| `maxUses` | `skillSpent: boolean` → `skillUses: number` | §4.4a |
| 대상 종류 | `targetKind` / `targetCount` | §4.4b |
| `MAFIA_LEAD_POOL` | 리드를 풀에서 뽑고 킬 예산을 재정의 | §4.4c |

**유저에게 보이는 변화: 없음.** 정확히는 밤 결과가 클릭 즉시가 아니라 아침 직전에
표시되는 것 하나뿐이다. **이게 이 로드맵에서 가장 중요한 시즌이다** —
시즌 1~3의 콘텐츠 12개 중 9개가 여기에 의존한다.

*검증 기준:* 기존 [테스트](tests/) 전부 통과 + 밤 정산 순서 테스트 신규 작성.
`npm run verify` 클린.

### 8.4 밸런스 패치 방향 (우선순위 순)

| 순위 | 항목 | 현재 | 제안 | 근거 |
| :-: | --- | --- | --- | --- |
| **1** | 소인원 마피아 수 | 6~9인 = 2명 | **6~7인 = 1명** | 6인 M=2는 첫 투표 1회로 게임 종료 (§5.2) |
| **2** | 첫 밤 무사 | 없음 | **6~8인에 적용** | 첫 투표에 정보 1단위 확보 (§5.5) |
| **3** | 은폐자 공급 | 짐승인간이 11인부터 | **사기꾼 7인부터 + 짐승인간 리드 승격** | 6~10인에 은폐자가 0 (§4.4c) |
| **4** | 보호 계열 상한 | 없음 | **최대 2종** | 3연속 무효 밤 방지 (§3.5) |
| **5** | 조사·은폐 동시 제한 | 없음 | **사기꾼 ↔ 짐승인간 배타** / **마담 ↔ 짐승인간 배타** | 정보 경로 0 방지 (§3.5) |
| **6** | 기자 배치 | 풀에 상시 | **11인 이상 전용** | 조기 특종 = 게임 종료 (§3.3) |
| **7** | 건달 | 상시 | **보류 → 마담으로 대체** | 발언 봉쇄는 재미를 직접 깎음 (§2.2) |
| **8** | 무능력 시민 하한 | `MIN_PLAIN_CITIZENS = 1` | **유지** — 12인에서도 1명 보장 | 사칭 배경 필요 (§3.1) |
| **9** | 특수직 비율 | `SPECIAL_CITIZEN_RATIO = 0.5` | 유지, 인원별 재검토 | 12인에서 특수직 과다 여부 관측 후 |

**관측 지표 (패치 근거를 데이터로 만들기):**

| 지표 | 목표 | 벗어나면 |
| --- | --- | --- |
| 인원 구간별 시민 승률 | **50±5%** | 마피아 수 / 은폐자 배치 조정 |
| 평균 판 길이 | **5~10분** | `TIMING` 또는 라운드당 사망 수 조정 |
| 라운드 수 분포 | **3~5라운드** | 1~2라운드가 20% 넘으면 소인원 문제 |
| 직업별 승률 | **45~55%** | 55% 초과 = OP, 45% 미만 = 저성능 |
| 직업별 밴율 (밴픽전) | **≤ 20%** | 초과 = 재설계 대상 |
| 죽은 뒤 이탈률 | **≤ 30%** | 초과 = 관전 콘텐츠(예측전) 우선순위 상승 |
| 첫 판 완주율 | **≥ 70%** | 미만 = 속도전/튜토리얼 강화 |

**패치 원칙 셋:**

1. **수치보다 배치.** 능력을 약화시키기 전에 **어느 인원 구간에 등장하는지**를 먼저
   조정한다. 기자는 약한 직업이 아니라 11인 미만에서 강한 직업이다.
2. **배타 규칙 > 개별 너프.** §3.5의 문제 조합은 각 직업이 아니라 **조합**의 문제다.
   덱 빌더에서 조합을 막는 것이 개별 직업을 깎는 것보다 부작용이 적다.
3. **재미를 깎는 능력은 수치로 못 고친다.** 건달의 발언 봉쇄는 지속시간을 줄여도
   여전히 "내 턴을 빼앗기는" 경험이다. 이런 건 재설계 또는 제거다.
